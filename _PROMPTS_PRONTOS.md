# ⚡ BANCO DE PROMPTS PRONTOS — Copiar e Usar

> Cole um prompt abaixo em **qualquer IA** (ChatGPT, Claude, Gamma, Canva ou Tome) e substitua o que estiver entre `[CHAVES]`. Organizado por módulo. E abordagem prática para a realidade do professor brasileiro.

---

## 🧩 Módulo 1 — Slides rápidos com IA

**1.1 Roteiro completo de apresentação**
```
Atue como design instrucional. Crie o roteiro de uma apresentação de [10] slides sobre
[TEMA], para alunos de [segmento]. Para cada slide: TÍTULO, TEXTO (máx 3 linhas),
SUGESTÃO DE IMAGEM e, se houver, ATIVIDADE. Linguagem simples e acolhedora.
```

**1.2 Criança pequena (Infantil/Anos Iniciais)**
```
Crie slides para crianças de [IDADE] sobre [TEMA], com UMA GRANDE ilustração por vez,
cores vivas, texto de no máx 4 palavras e 1 pergunta lúdica ao final.
```

**1.3 Anos finais / Ensino Médio**
```
Crie slides para o [SEGMENTO] sobre [TEMA]. Inclua: 1 infográfico, 1 gráfico com dados
reais, 1 pergunta-problema no início, 1 mini-quiz de 3 perguntas e 1 desafio de aplicação.
Estilo moderno, sem poluição visual.
```

**1.4 Gerar roteiro p/ PowerPoint offline**
```
Monte o roteiro de 8 slides sobre [TEMA]. Para cada slide dê o título e 2–3 balinhas de texto.
Simples, para eu copiar no PowerPoint sem internet.
```

## ♿ MÓDULO 2 — Inclusão e AEE

**2.1 Texto em linguagem fácil (Easy Read)**
```
Reescreva o texto abaixo em língua fácil (Easy Read), para aluno com deficiência intelectual:
frases de no máx 6 palavras, palavras simples, 1 ideia por linha.
[TEXT]
```

**2.2 Sugerir pictogramas**
```
Para cada frase, sugira um pictograma (desenho simples) que ilustre a ideia.
Saída: FRASE → pictograma.
[1] Beba água. [2] Vá ao refeitório. [3] Vamos ler um livro.
```

**2.3 Conceito complexo em passos visuais**
```
Transforme o conceito [CONCEITO] em 5 passos simples, cada um com 1 frase curta + 1 imagem,
para aluno com deficiência intelectual. Inclua um jeito de mostrar o progresso ("passo 1 de 5").
```

**2.4 Rotina visual para TEA/TDAH**
```
Crie 6 slides de ROTINA (café da manhã → fim da aula) para aluno autista/TDAH: 1 imagem +
1 frase curta + ícone ✓ em cada um. Cores suaves, fundo claro, sem animações.
```

**2.5 Quadro de antecipação**
```
Monte um quadro de antecipação que mostre ANTES da aula a sequência de atividades,
o número total de passos e um slide final "Falta 1!".
```

**2.6 Slide de acalmo (crise/ansiedade)**
```
Crie 3 slides de ACALMO: 1) "Responde com calma", 2) "Respiro devagar: inspire, segure, solte",
3) imagem tranquila com "Você consegue". Minimalista, cores azul/verde.
```

**2.7 Legendas / transcrição**
```
Transforme o roteiro abaixo em boas legendas, quebrando a cada 2–3 segundos de leitura.
[TEXTO]
```

**2.8 Audiodescrição**
```
Gere uma audiodescrição (máx 2 frases) desta imagem para uma pessoa cega: cores, objeto
principal, ação e cenário. [DESCRIÇÃO OU ANEXO]
```

**2.9 Alto contraste / acessibilidade**
```
Sugira uma paleta de ALTO CONTRASTE para slides acessíveis (áudio alto azul-branco ou
fundo claro-preto). Evite verde+vermelho (daltonismo) e azul+violeta. Dê código hex em pares seguros.
```

**2.10 Revisar material para acessibilidade**
```
Revise esta apresentação para acessibilidade: alto contraste, sem texto sobreposto,
fonte legível (≥20pt), legendas e texto alternativo nas imagens. Gere a versão acessível.
```

## 🤖 MÓDULO 3 — IA na prática escolar

**3.1 Tutora de estudos (para o aluno)**
```
Atue como monitor de estudos do [fundamental/médio]. Pergunte em que assunto preciso de
ajuda e faça 3-4 perguntas de múltipla escolha. Quando eu responder, explique o que errei
de forma simples, com um exemplo. Nunca dê a resposta antes de eu tentar.
```

**3.2 Mapa mental de revisão**
```
Crie um mapa mental com [6] ramos sobre [TEMA], para revisar antes da prova. Em cada ramo,
3 palavras-chave e 1 exemplo. Feche com 1 questão-teste rápida.
```

**3.3 Autoria assistida (aluno usa IA SEM plagiar)**
```
Preciso criar um trabalho sobre [TEMA]. Não escreva pra mim: 1) faça um roteiro de 5 partes;
2) me dê 3 perguntas para eu pesquisar; 3) quando eu te mandar meu texto, me dê 3 críticas
para melhorar. Vou usar tudo com minhas palavras e te citar.
```

**3.4 Avaliar se um texto parece de IA (sem punir)**
```
Avalie este texto para dizer o quão provável foi escrito por IA, de forma leve. Me dê
3 marcas a favor de IA e 3 a favor de humano, e um veredito equilibrado. Indique como
confirmar com o aluno (perguntas de defesa oral).
[TEXTO]
```

**3.5 Criar rubrica à prova de IA**
```
Faça uma rubrica para a avaliação sobre [TEMA], com 4 critérios e 3 níveis (Excelente/Neutro/
Precisa melhorar) que exijam: exemplo da comunidade, fonte verificada e defesa pessoal. Tabela.
```

**3.6 Perguntas de defesa oral**
```
Gere 12 perguntas de DEFESA ORAL para um aluno sobre o trabalho [TEMA], divididas em:
básico, argumentação e aplicação na realidade. Linguagem clara.
```

**3.7 Tornar uma atividade à prova de IA**
```
Revise esta atividade: exige opinião própria, comparação de 2 fontes e exemplo da
comunidade? Se não, sugira 3 perguntas de defesa e 1 modificação para aplicar o saber.
[TEXT]
```

## 🎯 MÓDULO 4 — Gestão de sala de aula

**4.1 Quebra-gelo de 5 minutos**
```
Crie 5 dinâmicas de abertura de 5 minutos para turma de [SEGMENTO] sobre [TEMA],
mistas e divertidas, que façam todos falarem com o colega sem escrever.
Saída: nome da dinâmica, 1 frase de instrução, material (nenhum).
```

**4.2 Quiz educativo**
```
Crie um quiz de 8 perguntas sobre [TEMA] para o [SEGMENTO], com 3 alternativas cada,
marcando a correta. Adicione 1 pergunta-surpresa que valha bônus.
```

**4.3 Storytelling interativo**
```
Monte uma história interativa sobre [TEMA] para o [SEGMENTO]. A cada 2 parágrafos, dê
2 opções ao aluno (A/B). Inclua 3 finais possíveis ligados ao conteúdo.
```

**4.4 Caça ao tesouro de revisão**
```
Crie uma "Caça ao Tesouro" para revisar [TEMA]: 5 pistas/enigmas, cada resposta certa
dá a próxima. Para o [SEGMENTO]. Tom de desafio.
```

**4.5 O mesmo tema em 3 níveis (mesma turma)**
```
Escreva [TEMA] para o [SEGMENTO] em 3 níveis na MESMA turma: Nível 1 (fundamento, fácil),
Nível 2 (intermediário, exemplos), Nível 3 (avançado, problematização e criação).
Para cada nível: 1 explicação, 2 exercícios, 1 desafio.
```

**4.6 Combinados da turma (slides)**
```
Crie 6 slides de "Combinados da Turma" para o [SEGMENTO], cada um com 1 regra em frase
POSITIVA e 1 ícone grande (ex.: "Levantar o dedo para falar", "Errar ajuda a aprender").
Tom leve, cores alegres, letras grandes.
```

**4.7 Transformar regras em frases positivas**
```
Transforme estas regras em frases POSITIVAS (o que se faz) + 1 ícone simples por regra.
Formato de lista para mural. [REGRAS]
```

**4.8 Jogo "Bingo dos combinados"**
```
Crie o jogo "Bingo dos combinados" com 9 regras (cartela 3x3), 1 ícone por regra.
Explique como marcar e qual o prêmio coletivo (ex: +10min de recreio).
```

## 💡 Dicas finais de uso
1. Substitua sempre `[CHAVES]` pelos seus dados (tema, segmento, idade).
2. **Revise o conteúdo da IA** — ela pode errar fatos ou datas.
3. Adapte as cores/letras para seu turno e turma.
4. Use o `PLANO_DO_CURSO.md` para seguir a sequência pedagógica.
5. Guarde as apresentações geradas em subpastas por módulo para reaproveitar.
